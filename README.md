# 💬 Chat App — Envio de Mensagens

Este projeto é um site de chat simples, focado inicialmente no envio de mensagens.  
A ideia é construir uma base para um sistema de comunicação em tempo real, permitindo que os usuários enviem mensagens de forma rápida e prática.

🚀 **Status:** Em desenvolvimento — no momento, o sistema permite apenas o envio de mensagens.

💡 Em breve: funcionalidades como exibição de mensagens recebidas, múltiplos usuários e interface em tempo real.
